# RIDEY 앱

따릉이를 타기 전에 경보가 켜진 자전거를 보는 Flutter 앱이다. 켜면 로고의 점이 떨어지며 RIDEY가 뜨고(움직임 줄이기면 건너뜀), 첫 실행에서 시민 모드와 직원 모드를 고른다. 시민 모드에는 직원 화면이 없고, 직원 모드는 구별 경보 목록만 읽는다.

## 화면

시민 모드: 홈(네이버 지도와 2km 안 경보 목록), 자전거 확인(번호, QR, 번호판), 자주 쓰는 대여소, 자전거 상세. 상세 첫 화면에 연쇄 인원, 마지막 헛대여 시각, 다음 사람도 바로 반납할 확률, 자료 시각이 있고, '판단 근거 자세히 보기'에서 확률을 올리고 내린 이유를 본다. 위치를 쓸 수 없으면 홈은 저장해 둔 대여소를 보여 준다.

직원 모드: 구별 현황(여기서 실시간과 아침 목록을 고름), 대여소별 목록(지금 무엇을 언제 받았는지와 받기 실패를 한 줄로), 더보기. 현장 판정이나 사진 업로드는 없다.

조회 기록은 이 폰에만 남는다. 최근 14일, 위치는 약 500m 격자로 줄인다. 알림도 이 폰 안에서만 만들고, 사용자가 켜야 한다. 하루 한 번, 습관 시간 15분 전부터 그 시간이 끝날 때까지, 습관 위치 1km 안에 경보 자전거가 있을 때만 보낸다. 폰에 저장해 둔 옛 사본이거나 자료가 30분 넘게 늦으면 보내지 않는다.

## 실행

```sh
cd app
flutter pub get
flutter analyze
flutter test
flutter run
```

지도는 `app/.env`에 `NAVER_MAP_CLIENT_ID=…`를 적어야 나온다(git에 올리지 않음, `.env.example` 참고). 네이버 클라우드에 앱 ID(`kr.bikedoctor.heotgeoleumzero`)를 등록한 키여야 한다. Supabase 주소와 publishable 키는 앱 설정을 따른다. secret 키는 넣지 않는다. 대여소 좌표는 `assets/data/stations.json`에 들어 있다. 다시 만들려면 저장소 루트에서 `analysis/export_web.py`를 돌린다(`data/stations.json`에도 같이 쓴다).

Android 릴리스 매니페스트에는 `INTERNET`이 있다. 알림을 쓰려면 알림 권한과, Android에서는 부팅 뒤 예약을 위한 `RECEIVE_BOOT_COMPLETED`가 필요하다. iOS 배경 갱신 시각은 기기가 정한다.
